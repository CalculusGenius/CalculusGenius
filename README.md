# Calculus Genius

> **A mathematics education platform for learning calculus and beyond.**

[![Website](https://img.shields.io/badge/Website-Calculus%20Genius-blue)](https://calculusgenius.github.io/CalculusGenius/)

Calculus Genius is an independent mathematics education website covering calculus, multivariable calculus, vector calculus, differential geometry, and other advanced mathematical topics.

The project is designed to make higher mathematics accessible while maintaining mathematical depth and rigor.

## 🌐 Website

**Visit Calculus Genius:**
https://calculusgenius.github.io/CalculusGenius/

## 📚 Topics

The website currently covers topics including:

* Single-variable calculus
* Multivariable calculus
* Vector calculus
* Differential geometry
* Advanced mathematical topics
* Mathematical relations and connections

## 🎯 Philosophy

> Mathematics does not care about age.

Calculus Genius aims to encourage students to explore mathematics beyond the boundaries of a conventional curriculum.

The goal is not simply to provide formulas, but to develop mathematical intuition, rigorous reasoning, and curiosity.

## 📖 Features

* Structured mathematical topics
* Explanations and learning resources
* References to mathematical books and external resources
* Responsive web design
* Dark mathematical-themed interface
